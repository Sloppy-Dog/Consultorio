# Consultório

Projetos de automação para o consultório. Cada projeto fica em uma pasta própria.

| Pasta | O que faz |
|-------|-----------|
| [`Monta_Plano_Alimentar`](Monta_Plano_Alimentar/) | Lê o "Plano alimentar ativo" (PDF) do Dietbox e gera o plano no modelo Word personalizado, mais a cópia em PDF. |
| [`Gera_Receita`](Gera_Receita/) | Lê as receitas em PDF do Dietbox e gera um livro único em Word no papel timbrado (capa, índice, salgadas e doces em ordem alfabética). |
